# 长庚 · 东沙旧事 — 开局可玩原型 v0.1

## Windows 启动
1. 把整个压缩包完整解压到普通文件夹，不要在压缩软件中直接运行。
2. 双击 `Play-Windows.bat` 开始游戏。已附带官方 Godot 4.3 引擎，无需另装。
3. 要修改游戏，双击 `Edit-Windows.bat`，或在 Godot 4.3 / 4.4 中导入 `project.godot`，按 F6/F5运行。

首次运行会导入中文字体，可能需要稍等。启动器运行的是 Godot 原生项目，不是网页，也不是独立发行版导出的商业成品。

## 操作
WASD 移动；F 与附近人物、箱子、遗书、草药交互；鼠标左键朝鼠标方向攻击；I 背包/附件/简单合成；J 人物关系；Esc 关闭界面或打开菜单；F6 保存；F5 读取。对话用 F、Enter 或点击继续。

## 已完成流程
家中醒来 → 开箱领取三个工具与种子 → 重读遗书 → 拜访村长 → 铁匠领取《材料大全》 → 医馆领取《草药大全》 → 村南采集三株草药 → 背包合成回血药 → 告别村长 → 黑屏切换至长城 → 向裴肃报名 → 木桩练习 → 认识驻军 → 领取军籍腰牌。

三张地图具备角色移动、碰撞、近距离交互、中文对话、左侧任务追踪、物品与箱子存取、手册、基础合成、首次交谈信任与存档。可乱序探索，任务会核对已经做过的事情。草药本开局采完后不会自动恢复。

## 内容边界
这是“前30分钟内容范围”的可玩原型，快速通关约10—15分钟，完整阅读与探索约15—25分钟；没有通过强制等待凑时间，未经玩家实测校准。当前美术为程序绘制占位场景，未达到最终像素素材质量。

当前不含完整隐藏支线、出关怪物战、种植/伐木/采矿、装备数值、狼人、技能与闪避。工具和种子可领取与保存，但相关采集种植功能尚未开放。生命界面为开局固定值；回血药可制作，使用规则留到战斗版本。遗书正文是明确标注的暂用草稿，父母姓名与既定背景已落实。

不要删除 `assets` 或 `engine` 文件夹。源码主要在 `main.gd`，后续建议拆分地图、数据、界面与任务系统。

## 存档
完成主线步骤、领取物品、采集、制作、切换场景时保存。关闭窗口前可按 F6。不会自动加载，以免丢失开场体验；发现存档会提示 F5继续。
Windows存档一般位于 `%APPDATA%/Godot/app_userdata/长庚·东沙旧事/east_sand_save.json`。删除该文件可重新开始。

## 验证
Godot 4.3 无界面导入与运行通过。`tests/smoke.gd` 验证主线全程、乱序领手册、合成扣料、重复对话不刷信任、读写存档。测试会写入测试用户的存档，运行前请备份。
